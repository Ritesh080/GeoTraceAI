## Start a session
Open the command palette and select **Agent Client: Open chat view**. Select Claude Code, Codex, or Gemini CLI. Ask: “Read AGENTS.md and 00-Project/CONTEXT.md, then help with the next task.”

Use one agent to edit a given file at a time. Hand off through the shared notes rather than assuming agents share chat history.
