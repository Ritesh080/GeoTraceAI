Import evidence

Up to 1,000 records / 4 MB. Fields: name, entity_type, phones, emails, payment_identifiers, notes. CSV lists use semicolons; JSON lists use arrays.

Possible matches

A matching name or phone is a lead. Shared names, recycled numbers and inaccurate source records can link unrelated people. Emails and payment identifiers are unverified source claims.

Run a case search to review matches.
